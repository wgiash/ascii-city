# NEON-ZAKA

A living ASCII metropolis in a single HTML file. No libraries, no assets — just
JavaScript, Canvas, and characters.

Open `index.html` in a browser. That's it.

## What's inside

- A raycast 3D engine that renders walls, rooftops, ground, and water entirely
  as colored monospace glyphs, with per-column depth and painter's occlusion
- An endless wrapping city: streets, avenues, an elevated beltway, a winding
  river with promenades, piers, and suspension bridges with arched undersides
- A Mako reactor megastructure with engine intakes, pylons, smokestacks, and a
  giant rotating searchlight
- A population: 420 pedestrians on real sidewalks and crosswalks, traffic that
  holds at signals, buses, boats, planes, and helicopters
- A night sky with drifting clouds, a starfield, and five planets
- Web-swinging: hold right-click to fire a web at a building and swing on a
  gravity pendulum, Spider-style

## Controls

| Input | Action |
| --- | --- |
| Drag / two-finger swipe | Look around |
| WASD | Move |
| Space / Ctrl | Ascend / descend |
| Shift | Sprint |
| Hold right-click | Web-swing toward the cursor |
| M | Toggle the radar |
